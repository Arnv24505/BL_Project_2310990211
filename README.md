# Employment Management SaaS Assessment

Simple trainee-level jQuery + JSON Server implementation for Arnav Agarwal.

## Run

```bash
json-server --watch db.json --port 3001
```

Then open the HTML files with VS Code Live Server (recommended).

## Folders

- `arnav-directory` - Dynamic Employee Directory & Live Search Grid
- `arnav-attendance` - Attendance Tracker with Local Storage Sync

No React/Vue. jQuery 3.7 CDN + HTML/CSS/JS + JSON Server.
